# Rustly organization files

Community health files and shared workflows for
[Rustly](https://rustly.tech).

This repository contains the organization profile, contribution and security
guidance, issue and pull-request templates, and reusable GitHub Actions
workflows. It contains no application code.

## Where to start

| Repository | Contains |
| --- | --- |
| [web](https://github.com/rustly-tech/web) | The Rustly website |
| [content](https://github.com/rustly-tech/content) | Lessons and exercises |
| [server](https://github.com/rustly-tech/server) | The Rustly server |
| [judge](https://github.com/rustly-tech/judge) | Exercise checking and judging |

[View all Rustly repositories](https://github.com/orgs/rustly-tech/repositories).
